#      side, which the two traces alone cannot detect.
#   2. The `truth` column printed in the table, so a reader does not have to
#      open the JSON to check a number.
#

# when this file has been deleted. A hand-edited value here would be silently
# reverted by the next regeneration, and until then would not be what the
# generator produces - which is exactly how three `110.0`/`440.0` lines got in
